# Créditos y licencia — sonidos "imaginados" de Oído Jurásico

Ningún sonido real de un dinosaurio se ha conservado jamás como fósil: nadie
sabe con certeza cómo sonaban estas criaturas. Los audios de esta carpeta
(`trex.wav`, `triceratops.wav`, `velociraptor.wav`, `estegosaurio.wav`,
`braquiosaurio.wav`, `ankylosaurus.wav`, `pteranodon.wav`, `spinosaurus.wav`,
`dilophosaurus.wav`, `pachycephalosaurus.wav`, `compsognathus.wav`,
`diplodocus.wav`, `iguanodon.wav`, `parasaurolophus.wav`) son por tanto
**síntesis sonora original creada específicamente para DinoQuiz** (barridos
de tono y textura generados por código, sin muestras ni grabaciones de
terceros) — nunca se presentan como una reconstrucción científica demostrada,
sino como un sonido imaginado para el modo Oído Jurásico (PRD G4; ver también
`public/i18n/es.json`'s `oidoJurasico.imaginedSoundNotice` y
`oidoJurasico.answerReinforcement`, que refuerzan este mensaje antes y
después de cada ronda).
