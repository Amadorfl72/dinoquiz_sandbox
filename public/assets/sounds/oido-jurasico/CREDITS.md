# Créditos y licencia — sonidos «imaginados» de Oído Jurásico

Ningún sonido real de estas criaturas se ha conservado jamás: nadie sabe con
certeza cómo sonaban. Todos los audios de esta carpeta son **síntesis sonora
original creada específicamente para DinoQuiz** (barridos de tono y textura
generados por código, sin muestras ni grabaciones de terceros). Nunca se
presentan como una grabación real ni como una reconstrucción científicamente
demostrada, sino como un sonido **imaginado** para el modo Oído Jurásico
(PRD G4; ver `public/i18n/es.json` → `oidoJurasico.imaginedSoundNotice` y
`oidoJurasico.answerReinforcement`, que refuerzan este mensaje antes y después
de cada ronda).
