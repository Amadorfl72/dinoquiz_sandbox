# Créditos y licencia — ilustraciones del selector de modos

Todas las ilustraciones de esta carpeta (`quiz.svg`, `laberinto.svg`, `sombra.svg`,
`oidoJurasico.svg`, `parejas.svg`, `clasifica.svg`, `ordenaPorTamano.svg`,
`lineaDelTiempo.svg`) son obra original creada específicamente para DinoQuiz:
iconos vectoriales simplificados, de uno o pocos colores, sin texto incrustado,
pensados como ilustración decorativa por tarjeta en el selector de modos
(public/scripts/modeSelectorScreen.js, TRIOFSND-232). Cada icono se referencia
desde una tarjeta como `<img alt="" aria-hidden="true">` — nunca es el único
medio para identificar el modo, ya que el nombre visible y la etiqueta
accesible del botón proceden siempre de `public/i18n/es.json`.
